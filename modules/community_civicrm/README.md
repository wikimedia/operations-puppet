community-crm - the community civicrm site

This sets up a site with a CiviCRM instance for use by the Community Growth
and other teams.

Currently it runs on a production VPS instance.  It is reachable at:
https://community-crm.wikimedia.org

The development version is the 'cloud VPS' project 'civicrm-prototype'. You can
control the dev instance via https://horizon.wikimedia.org if you are a member
or admin of the project.  It is reachable at: https://community-crm.wmcloud.org

The CiviCRM software repo used for this project is in:
https://gitlab.wikimedia.org/repos/fundraising-tech/community-civicrm

To report bugs use https://phabricator.wikimedia.org and
tag a ticket with 'Fundraising-Backlog'.
