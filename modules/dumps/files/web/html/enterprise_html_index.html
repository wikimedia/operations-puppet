HTML Dumps Archive

HTML dumps of Wikimedia content - the rendered article HTML readers see, rather than wikitext source - predate Wikimedia Enterprise and remain archived on this site. The partial mirrors of Wikimedia Enterprise HTML dumps that were later hosted here were an experimental service that, as of 24 March 2025, are no longer replicated on this site.

For current HTML of Wikimedia content - regularly updated dumps via the Snapshot API, or individual articles via the On-demand API - visit Wikimedia Enterprise to sign up for a free account, or use your developer account to access the APIs within Wikimedia Cloud Services. The payload schema is described in the Wikimedia Enterprise API Data Dictionary.
